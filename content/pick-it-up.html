01 · The question

How small can the edit be?

I hypothesized that fine-grained LLM style steering can successfully be applied to VLAs to change high level robot actions.

I investigated whether there is an instruction following pathway for the instructions given to Vision Language Action (VLA) models and if it can be edited to influence behavior. While the Othello work intervened in the residual stream of a Transformer, we edited the VLA’s image token positions to redirect a robot’s simulated behavior.

We did find a pathway when giving the model the wrong instruction in π0.5 and patching in the image-position state from a run with the correct instruction. However, this only had a large effect after replacing the broader image-token state. Robot behavior failed to change reliably with the fine-grained, compact edits that we tested.

Classic LLM results often isolate a few important token positions for circuit analysis. Here, the instruction effect appears to depend on a broad image-associated state rather than a few selected positions. This does not prove that every position is necessary, or that a compact mechanism cannot exist; the compact approximations we tested did not reproduce the broad effect.

R = (aedit − aA) · (aB − aA) / ‖aB − aA‖²

Reading the plots. R measures progress from the receiving action A toward the donor action B. Zero means no progress along that axis; one means the same projection as B. It is not a task-success percentage or full-vector similarity.

02 · See the intervention

Same scene. Different instruction.

I used the LIBERO benchmark, which contains robot manipulation tasks to evaluate the models. LIBERO generates simulated camera images, object interactions, and task outcomes. The models control a simulated arm within the scenes. This gives us precise control over the starting conditions.

The key method was activation patching: I purposely gave the model the wrong instruction, then replaced its image-position keys and values with the ones from a different run using the correct instruction. The donor saw the same current observation. We repeated the replacement at every replan; no donor action or stored trajectory was copied.

Across the confirmation experiment, late-state repair completed 18/20 rollouts, compared with 19/20 under the clean correct prompt and 0/20 under both the conflicting prompt and the early-layer control. The later layers had the strongest effects; the earlier layers had almost no effect.

03 · Readability and control

The instruction is still readable

Conversely, editing text token states barely affects actions. In early layers, the model may keep a copy of the instructions in the text token states. However, these representations may no longer directly control a robot’s actions after the model processes a scene.

A linear probe decoded instruction identity from text positions with 100% accuracy through layer 16 and 99.87% at layer 17. Replacing text-position K/V moved the action only about 1% of the way along the axis toward the donor action.

An image token starts as a representation of part of an image. After the model processes the image and instruction together, its state can contain language information too. The intervention therefore tests an instruction-dependent image-associated state, rather than a purely visual signal.

04 · Methodology

What the model saw, and what changed

Our primary focus for this project was quantifying causal instruction influence. How much does a robot’s internal state, predicted actions, and ultimate behavior change from changing instructions?

I studied π0.5 using the LIBERO fine-tuned checkpoint. The main confirmation experiment had 80 episodes: 20 each for the correct prompt, wrong prompt, late-state repair, and early-layer control. These are 20 task/state pairs across two tasks, each evaluated in four conditions.

Episodes were only considered a success if a robot completed the goal, which was putting the correct object in the basket. Episodes were considered a failure if it completed the wrong task, became stuck, or didn’t finish within 280 simulator steps.

For reproducibility, the model revision is 8e174154ef5f6c60a8da12ae99c303d8963138c1. The code, experiment records, figure data, and audit are linked in the research repository.

06 · Background

Why I chose this question

This model biology question was inspired by Othello, especially using a model-native coordinate system to understand a hidden world state. Nanda et al. found linear representations of the board in terms of “mine” versus “yours.” This work has conceptual ties to the linear representation hypothesis.

My original hypothesis was that there is an identifiable safety circuit in world models such as JEPA. I tried to edit its hidden prediction of physical reality, but never established a reliable behavior to explain. To address this, I had some ideas around representational geometry that I began implementing but realized this was best saved for a future project. This led me to pivot to VLAs, which had clearly defined language and image token positions I could trace and intervene on.

Fine-grained control of models is increasingly important as we scale physical AI in the real world with VLAs and world models. Contributing to the applied interpretability toolkit for models that can take actions with real consequences is critical. This knowledge can help diagnose unsafe decisions and know which internal signals can control the models’ actions.

These steering methods have seen early results that are promising with CAFT in LLMs and COAST in VLAs. Most of all, I was interested in a less developed problem that had an ambiguous problem space, and in systematically using mechanistic interpretability techniques to make a contribution to that space.

07 · Limitations & future work

What this does not settle

Because I only had two tasks in the rollout confirmation, these effects may be an unusual part of the model behavior specific to these tasks. Also, because the interventions are across so many token positions broadly, I cannot explain the outcome in terms of an isolated circuit. There is a lack of specificity for the cause and effect here.

There was insufficient experimentation around the side effects of our intervention. In the follow-up, repaired behavior succeeded 9/10 times versus 10/10 for clean behavior. Repaired trajectories were longer in 8/10 pairs by a median of 15 steps, with one wrong-first contact and one separate failure. This small screen is exploratory, not a reliable estimate of a general side-effect rate.

In the future, we could address these problems by increasing the task diversity and sample size of the episodes, and by comparing the intervention and control on the same task, scene, and starting state. The statistical analysis should respect those paired cases rather than treating every coordinate or action as independent evidence.

Perhaps the highest-value next step would be to choose a stimulus set that specifically involved a stop/go mechanism. This would also have a stronger grounding in my interests in AI safety and applied interpretability. One limitation to the results is that the instructions are not commands explicitly saying things such as “stop.” Therefore, we can observe the effect of the instructions followed but cannot directly draw conclusions about safety or obedience generally.

The tested compact edits failed, but that does not establish that the representation is nonlinear or that no selective edit is possible. Broader replacement could preserve interactions that the smaller interventions disrupted.
