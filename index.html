Pick It Up: Does π0.5 Have an Editable Instruction Following Circuit?

September 5, 2026·Interpretability / Robotics

A late image-state edit redirects the robot to cream cheese. The position-dose curve shows why shrinking that edit proved difficult.

I hypothesized that fine-grained LLM style steering can successfully be applied to VLAs to change high level robot actions. Broad edits did redirect complete robot rollouts—but the compact alternatives we tested did not reproduce that control.
